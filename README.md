# Figma-1 | Developer Portfolio Website

A responsive developer portfolio website built by translating a Figma design into a structured, interactive frontend experience. Developed as part of the **JTG Frontend Home Assignment – Set 3**, this project focuses on visual consistency, layout precision, responsive styling, and modern web design practices.

## Overview

Figma-1 is a portfolio-style website designed to bring professional information and development work together in one interface. The layout follows a clean, minimal design with a distinctive yellow accent color, balanced spacing, and organized content sections.

The implementation focuses on recreating the provided design using core frontend technologies while maintaining a structured and maintainable codebase.

## Website Sections

| Section | Description |
|---|---|
| **Navigation** | Header with links to different website sections |
| **Hero** | Developer introduction with illustration and call-to-action |
| **Projects** | Six project cards with preview images and technology tags |
| **Recommendations** | Testimonial cards with ratings and profile information |
| **Contact** | Contact form and structured contact information |
| **Footer** | Quick navigation, portfolio categories, and social links |

## Design & Development Highlights

- Figma-to-Frontend implementation with attention to visual details.
- Card-based project layout with image previews and technology labels.
- Consistent typography, spacing, colors, and component styling.
- Structured navigation across multiple content sections.
- Responsive layout implementation for different screen sizes.
- Organized assets, stylesheets, and JavaScript files.

## Technology Stack

- **HTML5** – Semantic page structure and content organization.
- **CSS3** – Layout design, styling, visual hierarchy, and responsive implementation.
- **JavaScript** – Client-side interactions and DOM manipulation.

## Run Locally

**1. Clone the repository**

```bash
git clone https://github.com/ruby262007/Figma-1.git
```

**2. Navigate to the application folder**

```bash
cd Figma-1/jtg-portfolio/jtg-portfolio
```

**3. Launch the website**

Open `index.html` in your browser, or use the VS Code Live Server extension.
